# 5-10-minute PolicyAI demo outline

**0:00-1:00** Introduce PolicyAI and the synthetic company policy use case.

**1:00-2:15** Show the ten policy documents, ingestion script, chunking, embeddings and persistent ChromaDB.

**2:15-3:30** Walk through the Flask API routes and the evidence-only Groq prompt.

**3:30-5:15** Ask two in-scope policy questions. Point out the answer, citation IDs and source passages.

**5:15-6:15** Demonstrate an out-of-scope question and explain the evidence guardrail and its limitations.

**6:15-7:30** Open actual `eval/summary.json` and explain measured latency, retries and any manually verified quality metrics.

**7:30-8:30** Show GitHub Actions, README setup, and the AI tooling disclosure.

**8:30-9:00** Conclude with limitations and possible improvements.

Do not present unreviewed groundedness or citation accuracy as verified.
